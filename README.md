# Персональные top-10 рекомендации

Сравнение пяти моделей с нуля: **ItemKNN, iALS, EASE, FM с метапризнаками и ALS с собственным таргетом**. Датасет — [Amazon Reviews 2018 / Musical Instruments / 5-core](https://cseweb.ucsd.edu/~jmcauley/datasets/amazon_v2/).

Весь код, исследование, графики и выводы находятся в самодостаточном [solution.ipynb](solution.ipynb).

## Запуск

Откройте ноутбук в Jupyter или VS Code с Python **3.9–3.12** и выполните **Restart Kernel and Run All Cells**. Первая кодовая ячейка установит необходимые библиотеки; другие файлы репозитория для запуска не нужны.

Нужны интернет и несколько гигабайт свободной RAM. При каждом запуске данные скачиваются заново в память (около 210 МБ), модели обучаются, результаты появляются в ячейках. Кэш и отдельные файлы результатов не создаются; сохранённых выводов в ноутбуке нет.
